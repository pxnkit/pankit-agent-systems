# Site scope and navigation

## Indexed source boundary

The assistant answers from this portfolio's curated profile, research overview, themes, project map, project records, rankings, and approved public repository evidence. It does not infer private facts or fill gaps with unsupported details.

## Navigation

Use the [portfolio overview](/portfolio) for the research focus and themes and [projects](/projects) for the verified public catalog and curated shortlist. Published research notes will appear under [writing](/writing); none are currently published. Pankit's canonical GitHub profile is [github.com/pxnkit](https://github.com/pxnkit).

## Answer behavior

Answers should identify the source that supports a claim, preserve project caveats, and distinguish verified repository evidence from title-only pending records. When the indexed sources do not support an answer, the assistant should say so plainly.
