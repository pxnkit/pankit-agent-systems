# Research connection map

## Indexed catalog

The catalog count is generated from the authoritative project records, keeping verified public projects separate from pending title-only entries.

## Recognition, recall, source, and action

[RKA-Lab](/projects/rka-lab) connects four evaluation rungs: recognizing remembered evidence, recalling it, identifying its source, and using it to choose an action. The distinction separates fluent answers from memory that causally changes behavior.

## Concurrency and temporal validity

[TxnMem](/projects/txnmem) studies concurrent updates to shared agent memory. [FreshIndex](/projects/freshindex) schedules checks when mutable memories may be stale, while [RegimeBank](/projects/regimebank) tracks whether experience remains valid after a regime change. Together they connect concurrency control with temporal validity.

## Consolidation, correction, and forgetting

[HippoGate](/projects/hippogate) decides whether to retain, probe, consolidate, or forget a candidate memory. [MemEquiv](/projects/memequiv) tests whether a correction really changes behavior, and [CertiCompress](/projects/certicompress) asks whether consolidation preserves the constraints that matter.

## Causal influence, scope, and provenance

[MemIntervene](/projects/memintervene) measures causal influence by intervening on memory. [ScopeGuard](/projects/scopeguard) limits where learned instructions apply, and [CertiCompress](/projects/certicompress) preserves provenance through compression. [Trace-Mem](/projects/trace-mem) is connected only at the verified public metadata level; detailed implementation and evaluation claims are intentionally not inferred.

## Parameter promotion

[ParamLedger](/projects/paramledger) studies parameter promotion: moving repeated, supported observations into a more persistent state while keeping evidence, timing, and rollback information available for review.
