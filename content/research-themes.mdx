# Research themes

## Agent memory and adaptation

This theme studies what an agent should retain, consolidate, correct, or forget. It treats memory as a controlled state that must remain useful across changing contexts rather than as an unbounded transcript.

## Information retrieval and evidence

This theme studies recall, source recollection, provenance, temporal validity, and selective evidence acquisition. The goal is to retrieve evidence that is not merely similar to a query, but relevant, attributable, and timely enough to support a decision.

## Test-time learning

This theme studies safe adaptation during use, including when repeated observations justify parameter promotion and when uncertain evidence should stay outside persistent model state. Adaptation is evaluated as a governed process rather than an automatic update.

## Search-guided reasoning

This theme treats reasoning as a search over hypotheses, evidence requests, and possible actions. Search should expose uncertainty, respect constraints, and stop with clarification or abstention when the available evidence cannot support a reliable choice.

## Reliable tool agents

This theme studies agents that act through tools under concurrency, scope, and failure. Reliability depends on typed state changes, causal influence tests, pre-action verification, and traceable boundaries between observation, decision, and effect.
