# Selected applied AI systems

## ContextMemory

ContextMemory is a research prototype for retaining useful AI-agent context. It uses Python, PostgreSQL, vector retrieval, RAG, and graph representations to maintain dynamic context graphs, extract semantic and episodic facts, identify relationships, and retrieve relevant context for future queries.

## AIxAI Multi-Agent Workflows

AIxAI Multi-Agent Workflows explores agent generation and orchestration with LangGraph, Pydantic AI, Supabase, MCP, and agentic RAG. The workflow automates document crawling, chunking, storage, semantic search, and project-level question answering.

## HomeSage

HomeSage is an applied property-recommendation prototype. It combines a machine-learning regression pipeline with data preparation, feature engineering, exploratory analysis, and a REST API for property recommendations.
